# Guardian 고객 라이선스 발급 운영 절차

이 문서는 현재 License API 구현을 기준으로 작성했습니다. 실제 고객 라이선스 발급은 결제/계약 확인 후 운영자가 수행합니다. QA 테스트 발급과 유료 고객 발급을 혼용하지 않습니다.

## 현재 구현으로 가능한 발급 정책

- DB 제품 코드: `guardian-pro` (신규 공통 제품 migration 기준). 서명 entitlement의 플랫폼 공통 product claim은 `guardian`이며, Android 구형 `guardian-android` claim도 검증기가 호환합니다.
- 유효 기간: 1~36,500일
- 최대 기기 수: 1~20대
- 기본값: 365일, 1대
- 고객 연결: 고객명과 이메일을 함께 입력해야 하며, 주문번호는 선택
- 동일 이메일 고객은 기존 고객 레코드에 연결되고 이름이 갱신됩니다.
- 라이선스 키 원문은 발급 응답에서 한 번만 반환됩니다. 해시 및 조회용 식별자만 DB에 보관합니다.
- 키를 분실한 경우 기존 키 원문을 조회할 수 없으므로 재발급/기존 키 정지 정책을 적용해야 합니다.

가격, 무료 체험 기간, 환불/만료 후 유예기간, 자동 갱신 및 결제 연동은 현재 이 API에서 자동 결정하지 않습니다. 실제 결제 승인 확인 없이 유료 라이선스를 발급하지 마십시오.

## 노트북 또는 모바일에서 발급

1. 노트북: `http://127.0.0.1:8787/admin`
2. 모바일: Tailscale 연결 후 `https://<노트북 MagicDNS 이름>/admin`
3. 관리자 토큰으로 인증합니다. 토큰은 브라우저 저장소에 저장하지 않으며, 종료 시 연결을 끊습니다.
4. 고객명과 이메일, 선택적 주문번호를 입력합니다.
5. 승인된 계약 기간을 일수로 입력하고 허용 기기 수를 지정합니다.
6. 발급을 누른 후 키를 고객 전달용 안전한 채널에 보관합니다. 페이지를 닫거나 새로고침하면 원문 키를 다시 볼 수 없습니다.
7. 발급 후 라이선스 목록과 감사 기록에서 상태 및 만료일을 확인합니다.

## API 계약

관리자 인증 헤더: `Authorization: Bearer <GUARDIAN_ADMIN_TOKEN>`

발급 요청: `POST /v1/admin/licenses`

요청 JSON 예시(테스트용 형식이며 실제 고객 정보/키가 아닙니다):

```json
{
  "validDays": 365,
  "maxDevices": 1,
  "customer": {
    "name": "고객명",
    "email": "customer@example.com",
    "orderRef": "결제 주문번호"
  }
}
```

응답에는 `license.license_ref`, `license.expires_at`, `license.max_devices` 및 최초 1회 표시되는 `licenseKey`가 포함됩니다. 실제 키는 로그나 문서에 복사해 넣지 마십시오.

## 정지 및 기기 관리

- 라이선스 정지: 관리자 화면에서 해당 라이선스의 정지 동작을 실행합니다. 활성 기기도 함께 해제됩니다.
- 기기 1대 해제: 해당 라이선스의 기기 목록에서 해당 기기만 해제합니다.
- 고객의 이메일/이름은 고객 목록에서 확인할 수 있습니다.
- 모든 발급/정지/활성화/기기 해제 동작은 감사 기록으로 남깁니다.

## 운영 전제 및 미완료 사항

- 운영자 토큰은 노트북의 `%LOCALAPPDATA%\Guardian\license-api\.env`에 있으며 GitHub 또는 앱에 등록하지 않습니다.
- 운영 라이선스 서명 개인키는 기존 노트북 License API에 보관합니다. 이 절차는 새 키를 생성하거나 기존 키를 교체하지 않습니다.
- QA 라이선스 발급·활성화·갱신·해지·정지 통합 검증은 별도 QA 결과로 확인된 범위입니다. 이 문서만으로 유료 고객 발급이나 결제 완료를 주장하지 않습니다.
- 결제 게이트웨이/웹훅, 자동 결제 검증, 세금계산/영수증, 고객 이메일 자동 전달, 가격 정책, 환불/분쟁 처리 및 운영자 권한 분리는 별도 운영 결정과 구현이 필요합니다.
- 실제 고객 라이선스는 고객 식별정보와 결제/계약 승인 근거가 확보된 후에만 발급합니다.
