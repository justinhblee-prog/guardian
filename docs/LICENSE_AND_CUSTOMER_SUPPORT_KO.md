# Guardian 라이선스 및 고객지원 운영 설계

## 라이선스 상품 정책

- Free: 무기한, 기본 보호 기능
- Pro 단기권: 7일 (중복 발급 방지 정책은 운영 전 별도 적용 필요)
- Pro 월간: 30일
- Pro 연간: 365일
- Pro 선불: 30일 또는 90일
- Pro Lifetime: 만료일 없는 영구 권한

현재 라이선스 API의 관리자 발급은 상품 코드(`short_7d`, `monthly_30d`, `quarterly_90d`, `annual_365d`, `custom`)와 `validDays`, `maxDevices`를 함께 검증합니다. 고정 상품의 기간을 임의로 바꾸면 서버가 발급을 거부하고, 발급 감사 기록에 상품 코드가 남습니다. 상품 코드별 가격·결제 연동·7일권 중복 발급 방지 및 Lifetime의 무기한 만료 모델은 별도 구현과 검증이 필요합니다. Lifetime을 임의의 100년짜리 라이선스로 대체하지 않습니다.

권장 기본 기기 수는 2대이며, 관리자 화면에서 고객별로 조정할 수 있도록 유지합니다. 앱은 짧은 수명의 서명된 entitlement를 주기적으로 갱신하고, 서버가 라이선스 만료·정지 여부를 최종 판단합니다.

## 고객지원 메뉴

앱 안에 다음 메뉴를 제공합니다.

1. 자주 묻는 질문: 설치/보호/VPN/앱 제외/필터/업데이트/라이선스/결제
2. 문의하기: 질문, 오류, 결제, 라이선스 카테고리
3. 의견 보내기: 기능 제안과 개선 의견
4. 오류 신고: 오류 설명 및 사용자가 선택한 진단 정보
5. 내 문의 내역: 접수 번호와 조회 비밀 코드로 상태 및 답변 확인

진단 정보는 명시적 동의가 있을 때만 첨부합니다. 라이선스 원문 키, 관리자 토큰, 비밀번호 및 기기 고유 식별자는 문의 본문에 포함하지 않습니다.

## 현재 추가된 기능

- 관리자 라이선스 발급 화면은 7/30/90/365일 상품을 명시적으로 선택하며, 서버는 상품 코드와 기간의 불일치를 거부하고 발급 감사 기록에 상품 코드를 남깁니다.
- Android 설정 화면에 고객지원 센터를 추가했습니다: FAQ, 문의/의견/오류/결제/라이선스 접수, 접수 번호와 비밀 코드 기반 답변 조회.
- 노트북과 모바일 브라우저에서 사용할 수 있는 반응형 관리자 라이선스 화면에 고객 문의함과 답변/상태 변경을 추가했습니다.

## 서버 API

- `POST /v1/support/tickets`: 고객 문의 접수. 접수 번호와 256비트 조회 토큰을 1회 반환하며 DB에는 조회 토큰의 SHA-256 해시만 저장합니다.
- `POST /v1/support/tickets/lookup`: 접수 번호와 조회 토큰을 요청 본문으로 전달해 본인 문의 및 답변 조회. 조회 비밀 코드를 URL이나 서버 접근 로그에 남기지 않습니다.
- `GET /v1/admin/support/tickets`: 관리자 인증이 필요한 문의함.
- `POST /v1/admin/support/tickets/{id}/reply`: 관리자 답변 및 상태 변경.
- 고객 접수, 문의 조회, 관리자 문의 작업은 기존 요청 제한기를 통과합니다.

기존 운영 DB에는 백업 후 `migrations/002_shared_rate_limit_buckets.sql`, `migrations/003_support_tickets.sql`, `migrations/004_customers.sql`을 순서대로 적용해야 합니다. `server/license-api/windows/Apply-GuardianLicenseMigrations.ps1`은 이 순서를 지키고 백업 및 `/ready`를 확인합니다. `schema.sql`에도 신규 설치용 테이블 정의가 포함되어 있습니다.

선택 이메일은 관리자가 문의에 회신할 때 참고하는 연락처로만 저장됩니다. 현재 메일 발송/알림 기능은 구현되어 있지 않으며, 고객은 접수 번호와 비밀 코드로 앱에서 답변을 조회합니다.

## 아직 완료로 간주하지 않는 항목

- Android 실기기에서 문의 제출·답변 조회 UI 및 키보드/스크롤 사용성 검증
- 관리자 문의함의 실기기 모바일/노트북 반응형 확인
- 메일 알림, 첨부파일 업로드, 스팸 방지 추가 계층
- 월간/연간 결제 공급자 검증 및 결제 웹훅 멱등 처리
- 체험판 계정 중복 발급 방지, Lifetime 무기한 권한 모델
- 운영 DB 마이그레이션 및 API 통합 테스트 실행

운영키와 라이선스 서명 개인키는 앱이나 저장소에 넣지 않습니다. 개인키는 서버의 비밀 저장소에만 두고 앱에는 검증 공개키만 포함합니다.
