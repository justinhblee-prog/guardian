# 보관 문서 안내

이 디렉터리는 과거 시점의 인수인계·빌드 환경 스냅샷과 체크섬 목록을 보존합니다.

- 이 문서들은 작성 당시의 기록이며 현재 버전, 현재 커밋, 최신 빌드 결과를 나타내지 않습니다.
- 현재 진행 상태는 저장소 루트의 `progress.md`, `RELEASE_STATUS_KO.md`, `VERIFICATION.md` 및 최신 GitHub Actions 결과를 기준으로 확인합니다.
- `SHA256SUMS-legacy.txt`는 과거 파일 집합의 체크섬 기록입니다. 현재 파일 무결성 검증에 사용하지 마십시오.
- 보관은 기록 보존 목적이며, 오래된 문서를 현재 운영 절차로 사용하지 않도록 분리한 것입니다.
