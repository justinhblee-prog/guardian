# 앱 실행 중 VPN 자동 일시중지

## 목적

일부 금융·결제 앱은 해당 앱의 네트워크 경로가 VPN에서 제외되어 있어도 기기 전체에 VPN 연결이 활성화되어 있다는 이유로 실행 또는 결제를 차단할 수 있습니다. 이 경우 앱별 트래픽 제외만으로는 호환성 문제가 해결되지 않습니다.

Guardian은 사용자가 명시적으로 선택한 앱이 화면에 표시되는 동안 VPN 터널을 일시 중지하고, 선택 앱이 닫히면 VPN을 자동으로 다시 연결하는 선택 기능을 제공합니다. 앱 목록 조회 전에는 기존 앱 인벤토리 안내에 동의해야 합니다.

Samsung Wallet 관련 알려진 호환성 사례와 유사한 동작은 [AdGuard의 Samsung Pay 호환성 안내](https://adguard.com/kb/adguard-for-android/solving-problems/samsung-pay/)를 참고했습니다.

Samsung Wallet 호환성 설정에서는 Wallet의 화면 앱 패키지 `com.samsung.android.spay`를 선택합니다. 별도 시스템 구성요소인 `com.samsung.android.spayfw`는 PaymentFramework이며, 자동 일시중지 대상은 Wallet 본체로 지정합니다.

## 사용자 동작

1. 설정에서 **앱 실행 중 VPN 자동 일시중지 앱**을 선택합니다.
2. Android의 **사용 정보 접근** 화면에서 Guardian 권한을 사용자가 직접 허용합니다.
3. 자동 일시중지를 켭니다. 활성화 전 전체 VPN 보호가 중단된다는 확인 안내를 표시합니다.
4. 선택한 앱이 포그라운드로 전환되면 Guardian이 TUN 인터페이스를 닫고 전체 VPN 보호를 일시 중지합니다.
5. 선택한 앱의 Activity가 모두 백그라운드로 전환되면 Guardian이 VPN을 다시 설정하고 기존 DNS 규칙 및 앱별 제외 설정을 재적용합니다.

## 보호 범위와 안전장치

- 자동 일시중지는 **앱별 트래픽 제외와 다릅니다**. 선택 앱 하나의 트래픽만 우회하는 것이 아니라, VPN 터널 전체를 닫습니다.
- 일시중지 중에는 선택 앱뿐 아니라 기기의 모든 앱이 Guardian DNS 보호를 받지 못합니다. UI와 알림에 이 사실을 분명히 표시합니다.
- 기본값은 꺼짐이며, 사용자가 앱을 선택하고 사용 정보 접근을 허용한 뒤 명시적으로 활성화해야 합니다.
- Android의 사용 정보 접근 권한이 취소되면 자동 일시중지를 끄고, 이미 일시중지된 보호는 가능한 즉시 복구합니다.
- 사용자가 Guardian 보호를 명시적으로 중지하면 자동 재연결하지 않습니다.
- 선택 앱 이름과 패키지 ID는 현재 포그라운드 여부 판정에만 메모리에서 사용합니다. 사용 이력을 저장하거나 서버로 전송하지 않습니다.
- Android 프로세스가 재시작되면 저장된 보호 의도를 확인하고, 모니터를 다시 시작해 선택 앱이 이미 포그라운드인지 확인합니다.

## Android 권한 및 배포

- `android.permission.PACKAGE_USAGE_STATS`는 일반 런타임 권한이 아닙니다. 사용자가 Android 설정의 **사용 정보 접근** 화면에서 직접 허용해야 합니다.
- Guardian은 `UsageStatsManager.queryEvents()`의 Activity 전환 이벤트만 사용해 선택 패키지의 현재 포그라운드 상태를 추적합니다.
- Google Play 배포 시 사용 정보 접근은 민감한 접근 권한이므로, 핵심 기능 적합성·명확한 고지·스토어 선언 및 심사를 별도로 통과해야 합니다. Play 등록을 배제하지는 않지만 승인도 보장하지 않습니다.
- 직접 APK 배포와 Play 배포 모두에서 사용자가 기능을 켜지 않으면 사용 정보 접근을 사용하지 않습니다.

## 검증 기준

1. 포그라운드 이벤트가 선택 앱 패키지에 대해서만 일시중지를 유발하는지 단위 테스트합니다.
2. 동일 패키지의 Activity가 여러 개일 때 마지막 Activity가 종료될 때까지 일시중지 상태를 유지하는지 확인합니다.
3. Android 설정 앱을 테스트 대상으로 지정해 에뮬레이터에서 VPN 터널이 실제로 닫히고, Guardian으로 돌아오면 자동으로 다시 연결되는지 확인합니다.
4. 앱별 제외 목록, 사용자 규칙, DNS 필터 캐시가 자동 일시중지/재연결 후에도 보존되는지 확인합니다.
5. 실기기에서는 Samsung Wallet을 대상으로 결제 화면 진입, Wallet 종료 후 VPN 복구, 복구 실패 시 표시 상태를 별도로 검증합니다.
